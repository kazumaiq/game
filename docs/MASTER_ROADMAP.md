# WASH EMPIRE — Master Roadmap

Последняя актуализация: 29 октября 2026

Проект использует Vite, Phaser 3 и модульный JavaScript. Рендеринг — 2D Canvas с процедурно сгенерированными текстурами и псевдо-3D композицией, а не Three.js/WebGL-сцена. Игровая логика отделена в `GameState`, визуальная сцена — в `CarWashScene`.

## Архитектура и зависимости

```text
main.js -> createGame.js -> BootScene -> MenuScene / LocationSelectScene / CarWashScene
CarWashScene -> GameState + BALANCE
CarWashScene -> SaveSystem, DayCycle, StorySystem, TutorialSystem, AudioManager
CarWashScene -> HudUI, BusinessPanelUI, UpgradePanelUI, DailyContractsUI, ToastUI
```

`GameState` является источником истины; сцены и UI отображают состояние и вызывают доменные методы.

## Реестр систем

| Система | Состояние | Зависимости | Критерий готовности |
|---|---|---|---|
| Игровой цикл смены | Реализовано | GameState, DayCycle | Время смены, пауза и завершение не начисляют расходы повторно |
| Игрок и управление | Реализовано | Phaser input, joystick | WASD/стрелки/E и мобильный джойстик работают без прокрутки страницы |
| Моечные боксы | Реализовано | GameState.posts, CarWashScene | Свободен/занят/сломался/починен отражаются визуально |
| Многоэтапная мойка | Реализовано | BALANCE.services, WashProgressUI | Пена, смыв и финиш проходят последовательно; оплата один раз |
| Материалы и расходники | Реализовано | suppliesStock, BusinessPanelUI | Мойка недоступна при нулевом запасе; покупка пополняет запас |
| Очередь клиентов | Реализовано | customer balance, patience | Автомобили ждут, теряют терпение и уезжают при таймауте |
| Сотрудники | Реализовано | employees, posts | Работник обслуживает назначенный бокс и учитывается в расходах |
| Экономика | Реализовано | BALANCE, financialLog | Доходы, расходы, штрафы и награды проходят через GameState |
| Документы и инспекции | Реализовано | documents, inspections | Проверка применяет штраф только при отсутствии документа |
| Улучшения и расширение | Реализовано | upgrades, unlockPost | Уровни, стоимость, визуальные индикаторы и зависимости работают |
| Сюжет и конкурент | В работе | StorySystem, GameState flags | События конкурента меняют спрос, цену и решения |
| Ежедневные контракты | Реализовано | stats, save data | Цели дня, прогресс и награда сохраняются и не выдаются повторно |
| Сохранение | Реализовано локально | SaveSystem, LocalStorage | Старые данные мигрируют безопасно, прогресс загружается после перезапуска |
| Облачное сохранение | Не начато | Auth/backend | Синхронизация между устройствами с конфликтной стратегией |
| Город и районы | Частично | CarWashScene city dressing | Начальная территория читается; исследуемые районы ещё не добавлены |
| Конкурирующие предприятия | Частично | StorySystem | Есть сюжетная линия, но нет самостоятельной экономической симуляции |
| Графические настройки | Частично | MenuUI, MenuScene | Эффекты можно отключить; Low/Medium/High ещё не выделены |
| Мобильная адаптация | В работе | scale manager, safe-area CSS | Портрет, landscape и iOS Safari подтверждены на устройстве |

## Definition of Done

- Игровая механика вызывается через `GameState`, а не изменяет баланс напрямую в UI.
- Любая награда, расход и оплата идемпотентны.
- Unit-тесты и production build проходят.
- На 393×852 нет горизонтального overflow, модальные окна закрываются с клавиатуры и touch.
- Уведомления не перекрывают ключевые controls и соблюдают reduced-motion.
- Новая система добавлена в roadmap с зависимостями и критерием проверки.
