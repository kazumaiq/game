# Автомойка: Бизнес на грани 🚗💦

Изометрический business tycoon, симулятор управления автомойкой и ручного труда с сюжетной кампанией и развитием бизнеса.

## Особенности игры

- **Игровой движок Phaser 3.90.0**: 2.5D изометрический мир, физика движения, визуальные эффекты загрязнения, пены и воды.
- **Интерактивный персонаж**: Управление через WASD/Стрелки (ПК) или сенсорный виртуальный джойстик (Mobile).
- **Реалистичный цикл ручной мойки**:
  1. Машина заезжает в свободный пост.
  2. Персонаж подходит и нажимает кнопку взаимодействия (`E` / экранная кнопка).
  3. Поэтапная обработка: нанесение пены ➔ смывание ➔ сушка и финиш.
  4. Расчёт качества мойки, расхода материалов и оплата клиентом.
- **Глубокая экономика и баланс**:
  - Стартовый капитал: 6 000 000 ₽.
  - Расходы на открытие (аренда, разрешения, строительство, 2 поста оборудования, материалы, вывеска): 5 400 000 ₽.
  - Стартовый резерв: 600 000 ₽.
  - 3 уникальные локации (Придорожная территория, Жилой район, Деловой район).
  - Ежедневные коммунальные платежи и посуточная аренда (1/30 в день).
  - Поломки оборудования и возможность ремонта.
- **Персонал**: Найм и увольнение работников, которые самостоятельно обслуживают машины на постах.
- **Сюжет и конкурентная борьба**:
  - День 1–3: Запуск и адаптация.
  - День 4: Появление гиганта «КлинАвто» (сеть из 47 филиалов).
  - День 5: Демпинговая ценовая война (мойка за 100 ₽ у конкурента).
  - Предложение о выкупе бизнеса за 1 200 000 ₽ или борьба до победы через повышение качества и маркетинг.
- **Главное меню**: кинематографичный закатный город, неоновая автомойка, стеклянная карточка запуска и адаптивные кнопки.
- **Настройки**: громкость и звуковые эффекты, сохранение предпочтения виртуального джойстика.
- **Ежедневные контракты**: три цели на смену — поток клиентов, выручка и качество мойки. Прогресс сохраняется, за выполненные задачи выдаются денежные бонусы.
- **Сохранение прогресса**:
  - Версионированный LocalStorage (гостевой режим без внешних зависимостей).
  - Состояние контрактов и полученные награды сохраняются вместе с игрой.
  - Подготовлена интеграция Supabase (RLS, PostgreSQL schema, Auth).

## 🛠️ Установка и запуск

### 1. Требования
- Node.js 18+ (протестировано на Node v20)
- npm 9+

### 2. Запуск в режиме разработки
```bash
npm install
npm run dev
```
После запуска откройте `http://localhost:3000` в браузере.

### 3. Запуск автоматических тестов логики
```bash
npm test
```
Тесты запускаются через встроенный Node.js Test Runner без сторонних тяжелых библиотек.

GitHub Actions автоматически выполняет `npm test` и `npm run build` при push в `main` и на pull request.

### 4. Сборка для публикации (Production Build)
```bash
npm run build
```
Готовые статические файлы находятся в папке `dist/`.

## ☁️ Подключение облачных сохранений (Supabase)

1. Создайте проект на [supabase.com](https://supabase.com).
2. Выполните SQL-скрипт из `supabase/schema.sql` в Supabase SQL Editor.
3. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
4. Впишите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в файл `.env`.

## 🚀 Публикация на Vercel

Проект готов к деплою на Vercel «из коробки»:
1. Создайте репозиторий на GitHub и отправьте код:
   ```bash
   git add .
   git commit -m "feat: initial complete release"
   git push origin main
   ```
2. Импортируйте проект в Vercel:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Нажмите **Deploy**.
